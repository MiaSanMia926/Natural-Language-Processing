本仓库用于存储和整理 **自然语言处理（Natural Language Processing，NLP）课程作业**，集中保存各次作业的代码、实验结果、报告与运行说明，方便回顾学习过程、比较实验方法和管理后续作业。

## 什么是 NLP？

自然语言处理是人工智能、计算机科学与语言学交叉的研究领域，研究如何让计算机处理、理解和生成人类语言。它将文本或语音转换为可计算的表示，并通过规则、统计方法或机器学习模型完成具体任务。

常见的 NLP 任务包括：

- **文本分类与情感分析**：判断新闻类别、识别评论的情感倾向。
- **序列标注与信息抽取**：识别人名、地名、机构名等实体，从文本中提取结构化信息。
- **机器翻译**：将一种语言的内容转换为另一种语言。
- **问答与对话系统**：根据问题和上下文检索或生成回答。
- **文本摘要与生成**：提炼长文本的主要内容，或根据提示生成文本。

学习 NLP 时，通常会接触文本预处理、分词、特征表示、模型训练和效果评估等环节。词袋模型（BoW）以词是否出现或出现次数表示文本；Word2Vec、GloVe 等词向量方法将词映射为稠密向量；BERT 等基于 Transformer 的预训练模型则利用上下文构建表示。不同方法各有适用场景，需要通过具体任务和实验进行比较。

## 使用说明

1. 根据上方索引进入对应作业目录。
2. 阅读该作业的 README，按说明准备依赖与数据。
3. 在对应作业目录中执行运行命令，并查看实验结果与报告。

各次作业的依赖和数据要求可能不同，请以作业目录中的说明为准。数据集、模型权重和缓存等文件可能未包含在仓库中，需要按相应说明另行准备。
